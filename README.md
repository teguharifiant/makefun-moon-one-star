A one-star review of the Moon, in 120 characters or fewer, written by `main.ts`
to `/output/entry.txt`.

## The entry

> ★☆☆☆☆ Drifts 3.8 cm further away every year and never once apologised. Commitment issues.

89 characters. One star, one grievance, one reason: the Moon drifts about 3.8 cm
further from Earth every year and has never once apologised for it — a complaint
only the Moon can earn.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
